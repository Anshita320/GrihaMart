<img width="1911" height="969" alt="image" src="https://github.com/user-attachments/assets/2e49cdf3-de74-4bf4-9cfb-ae4caee383b2" /># 🛒 E-Commerce PHP Project

A simple and dynamic **E-Commerce Web Application** built using **PHP, MySQL, HTML, CSS, and JavaScript**.
This project allows users to browse products, add items to cart, and manage wishlist.

---

## 🚀 Features

* 🔍 Search Products
* 📂 Category-wise Filtering
* 🛒 Add to Cart (AJAX based)
* ❤️ Wishlist System
* 🛍️ Buy Now Option
* 📱 Responsive UI Design
* 🔐 Session-based Cart System

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Server:** XAMPP / Localhost

---

## 📁 Project Structure

```
project/
│── config.php
│── index.php
│── product.php
│── add_to_cart.php
│── wishlist.php
│── checkout.php
│── /includes
│── /images
```

---

## ⚙️ Setup Instructions

1. Install XAMPP
2. Move project folder to:

   ```
   htdocs/
   ```
3. Start **Apache** and **MySQL**
4. Import database into **phpMyAdmin**
5. Open browser:

   ```
   http://localhost/your-project-folder
   ```
